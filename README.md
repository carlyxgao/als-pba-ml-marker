# ALS-PBA-ML-Marker: Machine-Learning Protein Marker Panel for ALS Diagnosis from Plasma EV Proteomics

Analysis pipeline for discovering and validating a machine-learning plasma
extracellular-vesicle (EV) protein marker panel for diagnosing amyotrophic
lateral sclerosis (ALS), based on proximity barcoding assay (PBA) proteomic data.

- **Discovery cohort:** Jinan (n = 523)
- **External validation cohorts:** Qingdao (n = 311), Xiamen (n = 204)
- **Groups:** ALS (n = 288), lower-motor-neuron disease controls (DC, n = 198),
  cognitively intact healthy controls (HC, n = 272)

The pipeline reproduces the bulk-level analyses of the manuscript:

| Module | Content | Manuscript figure |
|---|---|---|
| 1 | Differential expression (limma/edgeR), GO/KEGG/Reactome enrichment, LASSO + random-forest feature selection → 12-protein panel | Fig 1 B–G, Fig 2 A–C, GO ontology panels |
| 2 | Multiclass ML modeling (RF/XGBoost/SVM/MLR), ROC/PRC in external cohorts, SHAP interpretation, 12-protein RF vs serum NfL | Fig 3 A–J, SHAP bar panels |
| — | DE threshold sensitivity analysis | Supplementary |

## Reproduction

```bash
# 1. Create the environment (~10 min)
conda env create -f scripts/environment.yaml
conda activate als-pba-ml-marker

# 2. Put the raw files (vendor PBA report zip, baseline xlsx, nfl.xlsx) in data/raw/

# 3. Run the full pipeline (bulk analyses)
Rscript scripts/run_all.R                # all steps
Rscript scripts/run_all.R --list         # list steps
Rscript scripts/run_all.R --only module1_de   # a single step
Rscript scripts/run_all.R --from module2_ml   # start from a step

# 4. Manuscript figure PDFs
Rscript scripts/analysis/figure3_abcd_pdf.R   # multiclass ROC/PRC (Fig 3 A–D)
Rscript scripts/analysis/nfl_roc_pdf.R        # 12-marker RF vs NfL (Fig 3 I–J)
```

Key outputs land in `results/`:

```
results/module1_main/csv/     # DE tables, consensus DEPs, LASSO/RF unions,
                              # 12-marker panel, GO/KEGG/Reactome, sensitivity grid
results/module2_main/csv/     # model benchmark, multiclass predictions,
                              # SHAP importances, 12-marker vs NfL AUCs
results/module1_main/fig/     # module 1 plots
results/module2_main/fig/     # module 2 plots
results/module2_main/pdf/     # manuscript figure PDFs
```

Main outputs regenerated by steps `module1_de` and `module2_ml`:

- **12-protein panel** (LASSO ∩ RF intersection, Jinan discovery cohort)
- **ALS vs non-ALS AUC**, 12-marker random forest: 0.987 (Qingdao) / 0.985
  (Xiamen); serum NfL: 0.788 / 0.783
- **Secondary three-class evaluation (ALS / DC / HC), random forest**:
  accuracy 87.2% (Qingdao) / 75.0% (Xiamen); macro-averaged AUC-ROC 0.985 /
  0.976; macro F1 0.869 / 0.736. The confusion matrices (Fig 3 G–H) show that
  most misclassifications occur between the DC and HC classes, while ALS
  samples remain clearly separated from both control classes.
- **SHAP top proteins** (ALS class, random forest)

## Notes

- Scripts derive the project root from their own location; no absolute paths.
- Several scripts use a skip-if-exists strategy: when re-running with changed
  parameters, move or delete previous `results/` outputs first.
